# Perfil de Vladimir Varón Rodas - Agente Inmobiliario RE/MAX

Una página web profesional y responsiva para presentar el perfil de redes sociales del agente inmobiliario Vladimir Varón Rodas.

## Características

- ✨ Diseño minimalista y profesional
- 📱 Completamente responsivo (móvil, tablet, desktop)
- 🎨 Colores sobrios y elegantes
- 🔗 Enlaces a todas las redes sociales principales
- ⚡ Animaciones suaves y efectos interactivos
- 🎯 Optimizado para conversión

## Personalización

### 1. Cambiar la foto de perfil

Reemplaza el archivo `profile-placeholder.jpg` con tu foto de perfil:

1. Guarda tu foto como `profile-placeholder.jpg` en la carpeta del proyecto
2. Asegúrate de que la imagen sea cuadrada (recomendado: 400x400px)
3. La imagen se mostrará automáticamente con bordes redondos y centrada en la parte superior

**Alternativa:** Edita el archivo `index.html` y cambia la línea:
```html
<img src="profile-placeholder.jpg" alt="Vladimir Varón Rodas" class="profile-image" id="profileImage">
```

### 2. Añadir el logo de la empresa

Reemplaza el archivo `logo-placeholder.png` con el logo de tu empresa:

1. Guarda tu logo como `logo-placeholder.png` en la carpeta del proyecto
2. Recomendado: formato PNG con fondo transparente
3. Tamaño recomendado: máximo 240x120px para mejor visualización
4. El logo aparecerá centrado al final de la página

**Alternativa:** Edita el archivo `index.html` y cambia la línea:
```html
<img src="logo-placeholder.png" alt="Logo" class="company-logo" id="companyLogo">
```

### 3. Personalizar colores (opcional)

Para cambiar los colores, edita el archivo `styles.css`:

- **Color principal:** Busca `#2c3e50` y reemplázalo
- **Color secundario:** Busca `#7f8c8d` y reemplázalo
- **Color de acento:** Busca `#e74c3c` y reemplázalo
